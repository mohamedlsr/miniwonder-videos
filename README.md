# MiniWonder 🌟

Vidéos éducatives pour enfants (6-8 ans), en français, pour la chaîne YouTube MiniWonder.

- `generator/` : programme qui fabrique les vidéos (dessins, animation, musique, voix).
- `videos/` : vidéos finies, prêtes à publier.
- `thumbnails/` : miniatures YouTube.
- `fonts/` : polices Fredoka et Nunito (licence SIL OFL).

Voix de synthèse : Piper, voix « siwis » (SIWIS French Speech Synthesis Database, CC BY 4.0), téléchargée au moment de la génération.
